# مسیر بندگی — نسخه پایه آفلاین Android

این مخزن یک نمونه اولیه قابل توسعه با رابط فارسی و راست‌چین است. زبان پیاده‌سازی Java و ذخیره‌سازی محلی SQLite است.

## امکانات موجود در سورس
- داشبورد روزانه با تاریخ شمسی، شمارش وضعیت‌ها و درصد پیشرفت.
- ساخت خودکار فهرست فعالیت‌های پایه برای هر روز.
- سه وضعیت فعالیت: انجام شد، ناقص، انجام نشد؛ ثبت فقط با انتخاب کاربر.
- افزودن فعالیت شخصی.
- دفتر محاسبه نفس با هفت پرسش و ذخیره/بازیابی روزانه.
- ثبت جلسه مهارت‌آموزی شامل مهارت، موضوع، مدت، درصد و یادداشت.
- گزارش آماری پایه روز جاری.
- انتخاب رنگ زمینه از هفت حال‌وهوای پیشنهادی.
- ذخیره دائمی داده‌ها در SQLite.

## ساخت APK در Android Studio
1. Android Studio نسخه جدید را نصب کنید.
2. پوشه `MasirBandegi` را با گزینه **Open** باز کنید.
3. نصب Android SDK Platform 35 و Android Gradle Plugin سازگار را تأیید کنید.
4. پس از Sync موفق، از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
5. خروجی debug معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

برای انتشار عمومی، امضای Release و آزمون روی دستگاه واقعی الزامی است.

## مواردی که هنوز تکمیل نشده‌اند
این نسخه APK آماده یا Release تأییدشده نیست. در محیط ساخت فعلی Android SDK، Gradle و ADB نصب نیستند و دسترسی شبکه برای دریافت آن‌ها نیز موجود نیست؛ بنابراین Build، نصب و آزمون دستگاهی انجام نشده است.

موارد تکمیل‌نشده: زمان‌بندی هوشمند برنامه هفتگی/زوج شمسی، قواعد یک‌روزدرمیان صدقه، جزئیات جلسات و رویدادهای هفتگی شخصی، اعلان‌های دقیق، پشتیبان‌گیری/بازیابی کامل، PDF، قفل زیستی، تصاویر مجاز و آفلاین اماکن، گزارش‌های روندی و نمودار، دستیار AI متصل به سرور امن. تم‌ها در این نسخه فقط رنگ‌بندی‌اند و عکس مکان مقدس نیستند.

## نکات فنی
- `minSdk 26` و `targetSdk 35`.
- برای جلوگیری از ثبت ساختگی، هیچ فعالیتی خودکار تکمیل نمی‌شود.
- هوش مصنوعی در این نسخه غیرفعال است؛ هیچ کلید API در APK قرار نگرفته است.
