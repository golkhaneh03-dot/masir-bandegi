مسیر بندگی — راهنمای ساخت APK بدون Android Studio
1) در github.com یک ریپوی خصوصی (Private) جدید بساز.
2) Add file ← Upload files: همه‌ی محتویات همین پوشه (از جمله پوشه‌ی .github) را آپلود کن و Commit بزن.
   اگر پوشه‌ی .github آپلود نشد: Add file ← Create new file، نام را  .github/workflows/build.yml  بنویس و محتوای فایل build.yml را بچسبان.
3) تب Actions ← «Build APK» ← منتظر تیک سبز (۵ تا ۸ دقیقه).
4) روی همان اجرا کلیک کن؛ پایین صفحه در Artifacts فایل masir-bandegi-apk را دانلود و از حالت zip درآور.
5) فایل app-debug.apk را به گوشی بفرست و نصب کن (اجازه‌ی نصب از منبع ناشناس را بده).
